# TechGo Assistant

AI-powered chatbot website using Google Gemini API for helping users with computer and laptop recommendations, tech support, and interactive conversations.

---

## 🚀 Features

- Modern AI chatbot interface
- Google Gemini API integration
- Dark / Light mode
- Responsive design
- Real-time chat interaction
- Simple frontend structure
- Easy customization
- Fast and lightweight

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/panjidiago27/gemini-chatbot-api.git
```

### 2. Open Project Folder

```bash
cd gemini-chatbot-api
```

### 3. Install Dependencies

```bash
npm install
```

---

## 🔑 Setup Gemini API Key

Create a `.env` file in the root directory:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Get your API key from:

- https://aistudio.google.com/app/apikey

---

## ▶️ Run Project

```bash
npm start
```

or

```bash
node server.js
```

## 🔒 Security Notes

- Never expose your Gemini API key publicly
- Use `.env` for environment variables
- Add `.env` to `.gitignore`

Example `.gitignore`:

```bash
node_modules
.env
```
